## 先纠正一个误区：Claude Code 没有独立的会员

Claude Code 跟着 Claude 账号走。官方快速入门文档列得很清楚，能用它的账号一共四类：

- **Claude 订阅**：Pro、Max、Team、Enterprise，官方推荐的方式
- **Claude Console**：API 预充值、按量扣费
- **云厂商接入**：Amazon Bedrock、Google Cloud 的 Agent Platform、Microsoft Foundry
- **企业自建网关**：管理员配好地址，登录直接走公司 SSO

对个人开发者来说，问题基本简化成二选一：订阅，还是 API 按量付费。

订阅的便利在于一个账号全覆盖：终端 CLI、桌面 App 的 Code 标签页、网页版、手机 App，加上 VS Code、Cursor 等 VS Code 分支和 JetBrains 系列 IDE 里的插件，全部吃同一份额度。换个入口不会重新计费，IDE 里的用量也一样算进总池子。不想碰终端的话，桌面 App 内置了 Claude Code，装个 App 就够用；装好后第一次运行 `claude`，按提示登录一次，凭据会保存下来，之后不用反复登录。

有个新手坑值得提前说：如果系统里设置过 `ANTHROPIC_API_KEY` 环境变量，Claude Code 会优先用它认证，走 API 计费而不是订阅额度。你以为在吃会员，其实账单在按量走。碰到“订阅额度怎么没动静”的情况，先查这个变量。

## Pro（$20/月）：先问自己一周用几次

Pro 是订阅里最便宜的一档。$20 一个月，网页版 Claude 和 Claude Code 共用，对本来就订阅了 Claude 的人来说，编程能力算是顺带解锁。

限制也是实打实的：**5 小时会话限制，外加每周限额**，而且 Claude 应用和 Claude Code 的所有活动共享同一个池子。白天在网页版聊了几轮长对话，晚上写代码就可能比预期更早撞线。

什么强度适合 Pro？粗略说，一周打开几次、改改小项目、写写脚本，够用。要是打算把它当主力，每天让 AI 写代码、跑测试、开并行会话，额度大概率撑不到月底。官方帮助文档对这类用户的建议也很直白：升级 Max 5x。

超量之后 Pro 用户有三条路：等额度重置、升级套餐，或者开通 usage credits（用量额度），撞限后按量付费继续用。第三条路后面细说。

## Max 5x 还是 Max 20x：先上 5x，别急着跳级

Max 分两档，命名就是倍数：5x 约为 Pro 用量的五倍，20x 是二十倍，价格分别是 $100/月和 $200/月。

选档逻辑官方文档写得明白：Pro 稳定撞线，升 5x；在 5x 上还稳定撞线，再升 20x。按需爬坡，不鼓励一步到位。

Max 还有一项额外待遇：Fable 模型有单独的每周限额。重度依赖这个模型跑任务的话，额度焦虑会小一些。

$100 的月费差价摆在眼前，稳妥的走法是先上 5x 用一个月，用 `/status` 观察消耗速度。如果每周限额对你形同虚设，再考虑 20x。20x 真正发挥价值的场景是重度并行：本地先用 plan 模式把方案聊清楚，然后一条 `claude --cloud` 把执行丢到云端，同时再开两三个会话跑别的任务。这种玩法对额度的消耗速度，Pro 和 5x 都顶不住。

## 撞了限额怎么办：三条路和两套计费系统

先把规则说全。Pro 和 Max 都有两层限制：5 小时会话限制，加每周限额。快到线时系统会弹提醒，算是留了缓冲，不会毫无预警地断掉。

超量后官方给了三条路：

1. **等重置**。5 小时会话限制到期自动恢复，每周限额同理。
2. **升级套餐**。Pro → Max 5x → Max 20x，按实际消耗往上爬。
3. **开通 usage credits**。保持原套餐，撞限后按量付费继续用。

第三条要单独讲，因为这里藏着两套并行的系统：Claude Code 撞限时会弹选项，问你愿不愿意用 API credits 继续跑；而 Claude Console 里有独立的 auto-reload 设置，余额不足时自动充值 credits。

只想老老实实用订阅额度、连付费提示都不想看见的话，官方给的操作是：终端里 `claude logout`，再 `claude login`，登录时只用订阅账号，不要添加 Console 凭据。之后 Claude Code 只吃套餐额度，不会再弹 API 付费选项。想盯余量，会话里输 `/status` 就能看到。

## Team 和 Enterprise：什么情况下才轮到它们

Team 按席位计费，每人每月大约 $25–30（年付更便宜），管理员统一开通和结算。五人以上、需要统一管账号管账单的团队，它是合理选择；独立开发者用它，功能上限和 Pro/Max 没本质区别，多付的钱买的主要是管理能力。

Enterprise 是定制报价，面向有合规和管控需求的公司。一个容易忽略的细节：Enterprise 里不是所有席位都自动带完整的 Claude Code 能力，云会话需要 premium 席位或 Chat + Claude Code 席位，管理员分配席位时要注意。

顺带把云会话说清楚：Pro、Max、Team 都支持，跑在 Anthropic 管理的云基础设施上，合上笔记本任务继续跑，计入套餐额度，VM 不单独收钱，手机上也能随时查看进度。

## 不想被月费绑住：Console API 按量付费

使用频率是“一个月碰几次”的话，$20 月费大半在打水漂，Console API 更合理：预充值 credits，按实际用量扣费，不用不花钱。首次用它登录 Claude Code 时，Console 会自动创建一个叫 "Claude Code" 的工作区，方便单独追踪这块的开销。

它的反面也明显：重度使用时按量计费比订阅贵得多，还得自己盯余额。一个简单的分界线：每周都会打开，选订阅；偶尔用一次，选 API。

**Claude Code 有免费版吗？**
官方列出的可用账号全是付费方案，没有免费档。想零成本试水，只能走 Console 充一小笔 API 额度这条路。

**IDE 里用 Claude Code 要另外付费吗？**
不用。VS Code、Cursor 及其他 VS Code 分支、JetBrains 系列 IDE 里的 Claude Code，都计入同一份额度。

本地会话会断，云会话不会。Pro、Max、Team 都支持云会话，任务在云端继续跑，进度随时能查。
